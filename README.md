# 오픈소스개발프로젝트(06팀)

**06팀(서대전)**: 최태진(팀장), 이정주, 이준형

**주제**: OCR Model을 활용한 성적 시각화 서비스

**세부 내용**:
현재 개신누리에서 성적을 조회하면 표로 성적을 보여주고, 이수학점만 보여주기 때문에 성적 변화를 시각적으로 확인하기 위해선 사용자가 직접 성적 data로 시각화를 진행해야하는 단점이 존재했습니다.
또한 졸업 학점을 확인하기 위해선 성적 조회 -> 학과 홈페이지에서 졸업 요건 확인을 해야하는 불편함이 존재했습니다.
이를 개선하고자 OCR Model을 활용하여 개신누리 성적 페이지 이미지를 업로드하면 시각화 및 졸업 학점 자동 계산을 진행해주는 서비스를 기획하였습니다.

## 레포지토리 설명

- `📁 class/`는 수업 실습 내용을 업로드하는 디렉토리로, 각 팀원 이름으로 디렉토리 이름이 되어 있으며, 해당 디렉토리에 학습 내용이 업로드 되어 있습니다.
- `📁 docs/` 디렉토리는 과제, 스크럼 일지, 에자일 문서가 업로드 되어 있습니다.
  - **agile_docs**: 페이지 구조, 유저 플로우 차트, 제품 백로그가 업로드 되어 있습니다.
  - **homeworks**: 최종 과제 이전 문서들이 업로드 되어 있습니다.
  - **final_homeworks**: 프로젝트 최종 결과보고서, 발표 PPT, 시연 동영 그리고 요구사항 정의가 업로드 되어 있습니다.
  - **weekly_sprint**: 주간 스프린트 문서가 업로드 되어 있습니다.

# 프로젝트 수행 후 느낌과 향후 발전 방향

## 최태진

프로젝트를 수행하며, 실제 현업에서도 사용되는 상태관리 라이브러리와 jwt 토큰, 스프링 부트, 스프링 시큐리티 등을 사용해보는 좋은 경험이었습니다.

진행 과정에서 처음 사용하는 기술이니만큼 학습 곡선이 존재하였지만, 이 또한 팀원들과 함께하여 이겨낼 수 있었으며, 협업의 중요성과 커뮤니케이션의 중요성을 체감하였고, 혼자 개발보다 팀원과 함께한다면 더 좋은 결과물을 만들어낼 수 있음을 알게 되었습니다.

저희 프로젝트는 초기 계획의 100% 구현에는 미치지 못했지만 예상치 못한 이슈들을 해결하는 과정에서 설계 단계의 철저함과 문서화의 중요성을 체감하였고,
특히 팀 협업 시 명확한 스펙 정의가 개발 효율을 좌우함을 깨달았으며, 향후 발전 방향으로는 자체 OCR 모델 고도화를 진행하고, 다중 이미지 분석으로 상세 리포트를 생성하며, 졸업요건·학사정보를 담은 Vector DB 기반 RAG 챗봇을 구축하여 분석 결과에 대한 맞춤 상담 기능을 제공할 계획입니다.


## 이정주

이번 프로젝트는 내가 자바 언어를 처음 사용해 보는 경험이었기 때문에 초반에는 문법과 개발 환경이 낯설었지만, 진행하면서 흥미로운 사실을 발견했다. C, Python등 내가 사용해왔던 언어들과 기본적인 로직은 매우 비슥하다는 점이다. 조건문, 반복문, 함수 구조 등 핵심 개념은 거의 동일했기 때문에, 자바만의 문법만 익히면 충분히 빠르게 적응할 수 있었다.

또한 이번 프로젝트에서는 스프링프레임워크를 활용하여 백엔드를 구현했는데, 스프링이 제공하는 계층형 구조와 의존성 관리 방식을 직접 적용해 보면서 백엔드 개발의 체계성과 확장성을 체감할 수 있었다. 프론트엔드와 백엔드를 연결하는 과정에서 서버–클라이언트 통신 구조를 자연스럽게 이해하게 되었고, API를 설계하고 주고받는 경험을 통해 전체 시스템의 흐름을 보는 시야도 넓어졌다.

학기 초반 배운 애자일방법론도 프로젝트에 조금씩 적용했다. 짧은 단위로 기능을 나누고 스프린트별로 진행 상황을 공유하는 과정이 프로젝트의 속도와 팀 간 소통에 큰 도움이 되었다. 
 이 방식 덕분에 문제를 초기에 발견하고 빠르게 개선할 수 있었고, 개발 과정 전반이 훨씬 유연하게 흘러갔다.

또한 프로젝트의 주요 기능 중 하나였던 데이터 시각화 작업을 수행하면서, 단순히 데이터를 처리하는 것이 아니라 사용자에게 ‘어떻게 이해하기 쉽게 보여줄 것인가’를 고민하는 경험도 얻었다. 이는 백엔드와 프론트엔드 모두를 경험할 수 있는 좋은 기회였고, 전체적인 서비스 품질을 결정하는 중요한 요소임을 깨달았다.

이번 프로젝트를 통해 새로운 기술을 배우는 과정뿐 아니라, 팀 협업과 전체 시스템 설계, 서버,클라이언트 구조 이해, 그리고 데이터 표현 방식의 중요성까지 다양한 요소를 종합적으로 경험할 수 있었다. 앞으로 더 복잡한 시스템을 설계할 때도 이번 경험이 큰 기반이 될 것이라 느꼈다.

## 이준형

이번 프로젝트를 하면서 느낀 점은 크게 두가지 입니다.

먼저 ocr을 사용했는데 이 과정에서 이미지의 노이즈, 기울기, 해상도에 따라 인식률이 천자만별임을 확인했습니다. 이를 해결하기 위해 이미지 전처리 기술이 인식 정확도에 중요한 역할을 한다는 것을 배웠습니다.

두번째로 추출한 데이터를 어떻게 시각화 할지에 대해 고민하면서 사용자 경험 중심의 사고를 기를 수 있었습니다.

향후에 발전방향으로는 저희 과 뿐만 아닌 다른 과의 성적 분석도 가능하게 만들고, 단순히 현재 성적을 분석해주는 것을 넘어 목표 학점에 도달하기 위해 필요한 조건들을 알 수 있게 만들고 싶습니다.
